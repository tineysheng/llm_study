# Agent Safety Sample

This file is located in `03-agent/safe-files` and is used by the restricted file reader demo.

Key points:

- Never trust file paths generated by the model.
- The file reader tool may only access the allowlisted safe directory.
- `../`, absolute paths, drive-letter paths, and wildcards should be rejected.
- Observation should only include necessary content to avoid leaking sensitive data into model context.
