# LLM & AI Agent 学习项目（Go 程序员版）

> 目标：用 Go 系统掌握 LLM 应用开发、RAG、Agent、MCP，并沉淀成可写进简历、可面试讲清楚的项目作品。

这个仓库不是单纯的学习笔记，而是一个从基础 API 调用逐步演进到 AI Agent 工程项目的练习仓库。每个阶段都要求同时完成三件事：

1. **概念理解**：知道技术解决什么问题、边界在哪里、常见坑是什么
2. **代码实现**：用 AI 辅助生成 Go 代码，但自己负责理解、调试和验收
3. **面试表达**：能用自己的话讲清楚设计取舍、优化方向和工程风险

详细任务和打卡记录见 [PROGRESS.md](PROGRESS.md)，概念笔记放在 [notes/](notes/)。如果开启新的 AI 会话，请先阅读 [AI_TUTORING.md](AI_TUTORING.md)，按里面的学习流程继续带我学习。

## 阶段目标

### 阶段 1：LLM API 基础

先掌握最小闭环：用户输入、消息历史、模型调用、流式输出、错误处理。重点不是“调通 API”，而是理解 **LLM API 是无状态的，记忆由应用层维护**。

完成后你应该能讲清楚：

- token、context window、temperature、streaming 的作用
- 为什么多轮对话要把历史消息传回 API
- 如何控制成本、延迟和输出稳定性

### 阶段 2：RAG 检索增强生成

实现一个能回答本地 Markdown 文档问题的知识库系统。重点是理解 RAG 的完整链路：文档切分、Embedding、向量存储、Top-K 检索、Prompt 拼接、答案生成和来源引用。

完成后你应该能讲清楚：

- RAG 和微调的区别
- chunk 大小、Top-K、召回率、准确率之间的取舍
- 如何排查“检索到了但回答不好”与“根本没检索到”的问题

### 阶段 3：AI Agent 与工具调用

实现一个能选择工具、执行工具、读取结果并继续推理的 Agent。重点是把 LLM 从“聊天模型”升级成“任务执行器”。

完成后你应该能讲清楚：

- Agent 和普通 Chatbot 的区别
- Function Calling / Tool Calling 的工程流程
- Agent Loop 的退出条件、最大轮数、安全校验和错误恢复

### 阶段 4：MCP 协议

把工具能力封装成 MCP Server，让外部 AI 客户端可以标准化调用。重点是理解 MCP 解决的是“工具接入协议统一”的问题。

完成后你应该能讲清楚：

- Host / Client / Server 的角色
- MCP 和直接 Function Calling 的区别
- 为什么 MCP 适合工具生态集成

### 阶段 5：求职作品集整理

把阶段 2 和阶段 3 打磨成主项目，补齐 README、架构说明、运行方式、效果截图、面试问答和简历描述。

完成后你应该拥有：

- 一个 RAG 项目：适合投 AI 应用开发、后端 AI 工程岗位
- 一个 Agent 项目：适合展示工具调用、任务编排、工程可靠性
- 一套面试表达：能讲清楚原理、代码和优化方向

## 快速开始

设置 API Key（PowerShell）：

```powershell
$env:OPENAI_API_KEY = "sk-你的key"
```

运行第一阶段程序：

```powershell
go run ./01-llm-basics
```

## 学习方式

后续采用“AI 导师 + 项目实战 + 问答考核”的关卡制学习：

1. **AI 设计知识点**：我先告诉你当前关卡要学什么、为什么重要、工作中怎么用
2. **AI 落地到项目**：我把这个知识点实现进 Go 项目，并解释关键代码和设计取舍
3. **你运行和观察**：你负责跑 demo、看输入输出、理解现象、提出不懂的地方
4. **AI 提问考核**：我围绕概念、代码、工程取舍和面试表达向你提问
5. **通过再进入下一关**：如果你回答得好，我们进入下一个知识点；如果没通过，就补讲、改代码、再练一次

## 学习原则

1. **可以用 AI 写代码**：关键是你要知道需求怎么拆、代码怎么看、问题怎么定位
2. **每个知识点必须进项目**：不只学概念，还要看到它在代码中的位置
3. **每个功能都要能解释**：能跑只是开始，能讲清楚才有求职价值
4. **优先做小闭环**：先做最小可用版本，再逐步工程化
5. **必须亲自验收结果**：运行、观察、提问题、确认行为是否符合预期
6. **通过问答再前进**：不要追求学得快，要确保能复述、能判断、能面试表达
7. **记录自己的理解**：笔记不是摘抄资料，而是沉淀面试表达
8. **面向作品集打磨**：阶段 2 和阶段 3 是最终简历重点
